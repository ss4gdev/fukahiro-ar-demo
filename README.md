# 深廣 3DとARの導線デモ

公開URL: https://ss4gdev.github.io/fukahiro-ar-demo/
通販側のデモ: https://ss4gdev.github.io/fukahiro-shop-demo/

表示商品と共通サンプルモデルを使い、3D表示と外部ページへの導線を確認するレビュー用デモです。全商品で同じマグロ握りサンプルを表示し、通販商品の正式モデルではありません。

AR側は深緑の「深廣｜3D・AR」ヘッダーと独立したスタイルを使用します。トップは価格なしの商品選択メニュー、「別のARを見る」はページ内の選択ダイアログです。商品画面の「通販へ戻る」「通販サイトに戻る」は、選択中商品のデモ通販詳細へ戻ります。ARメニューの戻り先はデモ通販の商品一覧です。通販側のサイトや既存のAR商品リンクは変更していません。

カートはブラウザ内のデモカートです。らくうるへの送信、注文、決済、在庫確保は行いません。個人情報入力はありません。
